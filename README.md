# Ember for Mac and Windows

Installer downloads for the Ember desktop app. The app, the account and everything else live at
[getember.space](https://getember.space); this repository exists only so the installers have a
stable public home.

| Computer | File |
| --- | --- |
| Mac, Apple silicon (M1 and later) | `Ember-mac-arm64.dmg` |
| Mac, Intel | `Ember-mac-intel.dmg` |
| Windows, 64-bit | `Ember-windows-setup.exe` |

The newest build is always at
`https://github.com/yatishGautam/ember-desktop/releases/latest/download/<file>`; the web app's
download buttons point there.
